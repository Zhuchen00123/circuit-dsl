## 3. 复核项 1：独立重推参考解

### 3.1 我的推导（独立于 a03/a06）

ODE：`tau*y' + y = v_in(u)`，`u = t - td`，`y(0)=0`，输入为延迟有限斜坡：
`v_in = 0 (u<=0) ; V0*u/T (0<u<=T) ; V0 (u>T)`。
积分因子法：`y(u) = (1/tau) * int_0^u e^{-(u-s)/tau} v_in(s) ds` ⇒

- `0 < u <= T`：`y = (V0/T)[u - tau(1 - e^{-u/tau})] = (V0/rho)*S(x)`，`rho=T/tau`，`x=u/tau`，`S(x)=x+expm1(-x)`
- `u > T`：`y = V0 + (y(T) - V0)*e^{-(u-T)/tau}`，`y(T) = (V0/rho)*S(rho)`

理想阶跃对照：`y_step = V0(1 - e^{-u/tau})`；对 `u>T`，`y_ramp - y_step = V0*C(rho)*e^{-u/tau}`，`C(rho) = 1 - (e^{rho}-1)/rho`（`rho<<1` 时 `C ≈ -rho/2*(1+rho/3)`）。

### 3.2 数值交叉验证（自写 RK4，完全不使用闭式）

RK4 定步长积分 `tau*y' + y = v_in`（h 随积分区间缩小，最细 `tau/5e5`），在 7 个 `u/tau` 上与我的闭式解比较：
