## 2. 物理设定与记号（沿用 lead 的固定设定，未改动）

- 一阶 RC 低通：`v_in(t)` 经 `R` 到节点 `out`，`C` 从 `out` 到地，输出 `v(out)`。
- `tau = R*C`；输入为**有延迟的有限斜坡**：延迟 `td` 后从 0 线性升到 `V0`，斜坡持续 `T`，之后保持 `V0`（下降沿在验证区间外）。
- `u = t - td`（相对斜坡起点）。ODE：`tau*dy/du + y = v_in(u)`，`y(0) = 0`。
- `x = u/tau`（无量纲时间），`rho = T/tau`（无量纲边沿宽度）。逐段：
  - `u < 0`：`v_in = 0`
  - `0 <= u <= T`：`v_in(u) = V0*u/T`
  - `u > T`：`v_in = V0`

## 3. 第 1 项：独立求解 ODE + 逐段求导回代

### 3.1 分段解析解

**支 1（`u < 0`）**：输入恒为 0，初值 0，齐次解在 `u=0` 前恒为 0：

    y(u) = 0

**支 2（`0 <= u <= T`，斜坡段）**：非齐次项 `V0*u/T`。
通解 = 特解 + 齐次解：特解取 `y_p = (V0/T)(u - tau)`（因为 `tau*(V0/T) + (V0/T)(u-tau) = V0*u/T` 成立），
齐次解 `A*exp(-u/tau)`。由 `y(0)=0`：`(V0/T)(-tau) + A = 0 => A = V0*tau/T`。故

    y(u) = (V0/T) * ( u - tau + tau*exp(-u/tau) )
         = (V0/rho) * ( x + expm1(-x) )              [x = u/tau, rho = T/tau]

**支 3（`u > T`，平台段）**：输入恒为 `V0`。以 `u=T` 为初值，解 `y = V0 + (y(T) - V0)*exp(-(u-T)/tau)`：

    y(T) = (V0/T) * ( T - tau + tau*exp(-T/tau) ) = V0 * ( 1 - (1 - exp(-rho))/rho )
    y(u) = V0 + ( y(T) - V0 ) * exp( -(u-T)/tau )      (u > T)

### 3.2 逐段求导并回代

| 支 | `y'` | `tau*y' + y` | 应等于 `v_in` |
|---|---|---|---|
| `u<0` | `0` | `0` | `0` ✓ |
| `0<=u<=T` | `(V0/T)*(1 - exp(-u/tau))` | `tau*(V0/T)*(1-e^{-u/tau}) + (V0/T)(u - tau + tau*e^{-u/tau}) = (V0/T)*u` | `V0*u/T` ✓ |
| `u>T` | `-( y(u) - V0 )/tau` | `-(y - V0) + y = V0` | `V0` ✓ |

（`T = 1e-12` 与 `T → 0` 时支 2 的 `(V0/T)(1-e^{-u/tau})` 必须用 `-expm1(-u/tau)` 求值，
否则 `1 - exp(-u/tau)` 自身就会灾难性相消；见 §5。）

## 5. 第 3 项：数值稳定性（灾难性相消）与稳定实现

### 5.1 相消机理（解析）

支 2 的括号项 `S(x) = x - 1 + exp(-x) = x + expm1(-x)`。当 `x << 1`：

    S(x) = x^2/2! - x^3/3! + x^4/4! - x^5/5! + ... = sum_{k>=2} (-1)^k * x^k / k!

**⚠ 符号更正**：任务书写的 `sum_{k>=2} (-1)^(k+1) x^k/k!` 符号整体反了。
独立核验（`rc_math2.py` §H，60 位 `decimal` 参考值）：`x=1e-2` 时
`S=+4.983374916805357e-05`；用 `(-1)^k` 得 `+4.983374916805357e-05` ✓，
用 `(-1)^(k+1)` 得 `-4.983374916805357e-05` ✗（首项 `-x^2/2`，会导致**物理上负的斜坡响应**）。
本报告一律采用 **`S(x) = sum_{k>=2} (-1)^k x^k/k!`（首项 `+x^2/2`）**。

`k >= 2` 的项单调递减（`|t_{k+1}/t_k| = x/(k+1) < 1`，当 `x < 3`），故交错级数的截断余项有界：

    |R_N| <= x^(N+1)/(N+1)!        （N 为保留到的最高阶）

### 5.4 相消在**电压量级**上的影响（避免过度归因）

`y = (V0/rho) * S(x)`。以 `tau=100 µs, V0=1 V, T=1 µs`（`V0/rho = 100 V`）实测

### 7.2 残差的形状：它是**纯齐次模态**误差

### 7.6 对旧归因两项的逐条判定

1. **「有限上升沿（1 ps）」**：不成立。
   1 ps 边沿的解析上界 `max|E| = V0*T/(2tau)*(1+O(T/tau)) = 5.000e-09 V`，

   作为**机制**，"有限边沿 → 纯 `e^{-t/tau}` 残差"是对的；但**时长对象错了 5.7 个数量级**：
   真实生效边沿是 500 ns（引擎夹取），而不是声明的 1 ps。
2. **「采样对齐」**：在现实现中贡献**恒为 0**。
   - `_probe/src/main.rs:322`：`let expected = 1.0 - (-t[idx]/tau).exp();` —— 用**实际返回时间** `t[idx]`；
   - `crates/circuit-backend/tests/adapter.rs:344`：同样 `1.0 - (-t[idx]/tau).exp()`；
   - `crates/circuit-cli/tests/e2e.rs:325`：同样 `1.0 - (-times[idx]/tau).exp()`。
   参考值与采样值用的是**同一个时间坐标**，邻近采样的时间偏差被构造性地消掉了。
   - 反过来，`docs/testing.md:201-204` 的「单单时间对齐就能贡献 1e-3 量级的电压差」作为**假设**数值上是成立的：
     若把参考值改在**名义目标时刻**求值，0.25τ 处 `|v(25.232 µs) - v(25.0 µs)| = 1.805e-03 V`
     （实测，`rc_math.py` §G）——它与 1.95e-3 V 同量级，这很可能就是旧归因的算术来源。
     但代码用的是实际返回时间，所以这一项对当前证据**不适用**。
3. 机制归因的正确表述（本轮应写进文档的版本）：
   **`_probe` 的 1.95e-3 V 残差 = 引擎把 PULSE `tr` 夹到 `.tran` 步长（500 ns）后，
   真实输入斜坡与"理想阶跃"参考模型之间的差异；量值由 `C(T_eff)*e^{-t/tau}` 给出，
   `T_eff = max(声明 rise, 引擎 step)`。它与 1 ps 声明边沿、与采样对齐都无关，
   也不需要在求解器里找 bug。**

### 7.7 与另一条「容差量级」解释的关系（不冲突，但不是首要因素）

引擎默认 `reltol=1e-3`、`vntol=1e-6`、`trtol=7.0`（`thevenin/src/newton.rs:169-171,204`），
`1.95e-3 V` 也确实落在 `/1 V = 0.2%` 这一"容差量级"里——所以"量级属于预期"这一句不假。
但**量级吻合不等于归因正确**：本报告给出了可复现的确定性机制（500 ns 夹取），
它能把这 5 个点复现到打印精度内，比"RELTOL 量级"更强、也更能指导修复。
两者不矛盾：求解器自身的积分误差在这 5 个点上被证明 ≤ 3e-12 V（RK4 对照，§3.3），
即残差**不需要**靠求解器误差来解释。

## 8. 可直接落地的稳定求值形式（建议 A08/A06 采用）

### 8.1 参考函数（Rust，已编译实跑）

在 `C:\Users\15185\AppData\Local\Temp\a03\rc_check.rs` 中编译运行通过（`rustc 1.98.1`）：

    /// 稳定形式：有延迟的有限斜坡 0 -> v0 over [0, t_rise]，之后保持 v0。
    /// x = u/tau, rho = t_rise/tau;  0 <= u <= T:  y = (v0/rho)*(x + expm1(-x))
    ///                                u > T:      y = v0 + (y(T)-v0)*exp(-(u-T)/tau)
    fn rc_ramp_ref(u: f64, tau: f64, t_rise: f64, v0: f64) -> f64 {
        if u <= 0.0 || t_rise <= 0.0 { return 0.0; }
        let s = |x: f64| if x < 1e-2 { series6(x) } else { x + f64::exp_m1(-x) };
        if u <= t_rise {
            v0 / (t_rise / tau) * s(u / tau)
        } else {
            let yt = v0 / (t_rise / tau) * s(t_rise / tau);
            v0 + (yt - v0) * (-(u - t_rise) / tau).exp()
        }
    }
    /// sum_{k=2..6} (-1)^k x^k/k! = x^2/2 - x^3/6 + x^4/24 - x^5/120 + x^6/720 - x^7/5040
    fn series6(x: f64) -> f64 {
        let mut t = x; let mut s = 0.0;
        for k in 2..=6 { t *= x / k as f64; if k % 2 == 0 { s += t } else { s -= t } }
        s
    }

要点：`x < 1e-2` 走 6 项级数（`x=1e-2` 处截断相对误差上界 3.97e-14），否则走 `x + exp_m1(-x)`（实测 ≤9.4e-15）；
`t_rise` 传 `T_eff`；导数用 `(V0/T)*(-expm1(-u/tau))`（支 2）与 `-(y-V0)/tau`（支 3），不要用 `1 - exp(-x)`。

### 8.2 `T_eff` 的取法（本轮最关键的落地细节）

    T_eff = max(声明的 rise, 引擎实际 .tran 步长)
    引擎实际步长 = TranSpec.output_interval（>0 时），否则 span/1000
      —— crates/circuit-backend/src/thevenin.rs:758-761
    引擎把 PULSE rise 夹到该步长 —— thevenin/src/waveform.rs:37

- 产品路径的 `output_interval` 默认是 `span/1000`（`thevenin.rs:761`）。
  `examples/rc_filter.cdsl:32` 是 `tran stop: 500.us, max_step: 500.ns`（未给 `output_interval` ⇒ 500 ns），
  而 `examples/rc_filter.cdsl:21` 声明 `rise: 1.ns` ⇒ **产品示例的真实边沿也是 500 ns**。
- 因此若想在 A08 里验证"接近理想阶跃"，只有两条路：
  (a) 显式声明 `rise >= output_interval` 并按 §8.1 建模（推荐，可重复）；
  (b) 把 `output_interval` 设到远小于声明 rise（每条 1 ps 需要 5e11 个输出点，不可行）。
  「声明 1 ps 上升沿」在 Thevenin 0.5.0 下**无法**被模拟成 1 ps。
- 在 `atol=1e-5 V, rtol=1e-3` 判据下，`T_eff = 500 ns` 的建模残差在 `0.5τ` 超限 3.78×、`1τ` 超限 1.44×（§6.2），
  所以 A08 若沿用理想阶跃参考一定失败——这不是求解器错误，是参考模型错了。

## 附录 B：解析结果速查

    tau = R*C,  u = t - td,  x = u/tau,  rho = T/tau

    u < 0        :  y = 0
    0 <= u <= T  :  y = (V0/rho) * ( x + expm1(-x) )
                     = (V0/T) * ( u - tau + tau*exp(-u/tau) )
     u > T       :  y = V0 + ( y(T) - V0 ) * exp( -(u-T)/tau )
                    y(T) = V0 * ( 1 - (1 - exp(-rho))/rho )

    y'(u)        :  0                        (u < 0)
                    (V0/T) * (-expm1(-x))    (0 <= u <= T)
                    -( y(u) - V0 ) / tau     (u > T)

    y_ramp - y_step = C(T) * exp(-u/tau),  C(T) = 1 - (tau/T)*(exp(T/tau) - 1)
                      = -(T/(2*tau)) * (1 + T/(6*tau) + T^2/(24*tau^2) + ...)
                      max|y_ramp - y_step| = |C(T)|  (在 u = T 处取到)

    S(x) = x + expm1(-x) = sum_{k>=2} (-1)^k x^k / k!     [正确符号]
         = x^2/2 - x^3/6 + x^4/24 - x^5/120 + x^6/720 - x^7/5040 + ...
         |R_N| <= x^(N+1)/(N+1)!
