## 当前发现与优先级

### P1：浮空用例的解释错误

位置：`_probe/src/bin/robustness.rs` 的 `base("float", ...)` 用例及 `docs/backend-evaluation.md` §4.6。

实际电路中电压源 v1 连接 a 与地并固定 a 为 1 V，电阻 r1 连接 a 与 b。b 存在经电阻和电压源到参考地的路径。开路负载时电阻电流为零、b 为 1 V 是正常结果，不能作为“gmin 掩盖浮空”的证据。

修复任务：

- 将此用例归类为合法开路输出的正例。
- 使用真正无参考的孤立电阻网络、仅经电容连接的网络作为独立反例。
- 检查已有 isolated-island 用例并尽量复用。
- 根据实际输出更新评估说明与 connectivity.rs 中引用该结论的注释。
- 不因这一证据错误直接删除现有前端检查；分别验证检查规则与后端行为。

验收：合法开路输出被接受；真正无参考的网络被前端明确诊断；后端原始行为据实记录，不根据有限数值反推 gmin 的具体作用。

### P1：瞬态误差归因缺少依据

位置：`_probe/src/main.rs::case2_rc_tran` 与 `docs/backend-evaluation.md` §5。

当前用例使用 1 ps 上升沿、100 us 时间常数，在五个选定样本附近用实际返回时间代入理想阶跃解析解，并以绝对误差小于 0.01 V 通过。评估记录将约 0.00195 V 偏差归因于有限上升沿与采样对齐。

这个归因不足：上升时间/时间常数仅为 1e-8；并且代码已经使用实际返回时间计算参考值，不能仅以选择邻近样本解释偏差。需要进一步区分初始化、时间积分、步长和容差的影响。此处尚未认定后端数值实现错误。

修复任务：

- 采用有明确延迟和有限斜坡的输入，与对应分段解析解比较。
- 比较整个有效输出区间，记录最大误差的时间点。
- 独立缩小最大步长、收紧容差，观察误差变化；只在有证据后归因。
- 将用例变成失败时返回非零状态的可重复验证，并补充产品适配器的针对性回归测试。
- 使用提示词 §17 的新阈值作为后续验证目标；若不满足，记录问题，不倒推此前测试已失败。

验收：输入和解析解匹配，误差位置与配置可复现，收敛趋势或剩余限制有据可查。

### P2：文档、目标契约与当前实现存在差异

- README 仍引用过时分压示例注释并解释其错误；实际 `examples/voltage_divider.cdsl` 已写为正确的 3 V / 2 mA。
- 提示词允许参数依赖 DAG；当前 README 与测试明确采用声明顺序求值并拒绝前向引用。这是功能差异，不应以“不会产生环”代替依赖链诊断的目标。
- 结果表达式求值器存在，但测试说明明确尚未接通 DSL/CLI；用户还不能直接通过源码完成任意传递函数表达式分析。
- 非零 AC 相位和正弦相位转换缺少数值覆盖，不能将零相位用例视为完整验证。

建议处理顺序：先修正文档的已知过时内容，再补非零相位测试；之后实现参数 DAG 与结果表达式入口，并同步语言规范。REPL 属于已有能力，应保留，不因原提示词未包含而回退。
